---
title: "Sauvegarder ses données"
---

Stylo ne constitue pas un service d'hébergement de données. Il est important de faire des sauvegardes régulières des documents sur Stylo, notamment pour les données sensibles ou importantes pour un collectif de recherche. 

Outre l'export d'articles ou corpus particuliers dans un format de votre choix en guise de sauvegarde sur votre machine, vous pouvez sauvegarder l'ensemble des articles auxquels vous avez accès, ceux de votre espace de travail personnel ou un d'un espace de travail partagé en particulier.

Pour cela, cliquez sur « Mon compte » en haut à droite de l'interface de Stylo, puis sur « Sauvegarder mes données », puis sur le bouton noir « Télécharger mes données ». Vous pourrez ensuite choisir entre sauvegarder toutes vos données, celles de votre espace personnel ou celles d'un espace particulier. Une fois cela déterminé, vous devez choisir entre exporter vos données en un fichier JSON général, ou un dossier .zip dans lequel vos articles seront séparés en dossiers (intitulés avec leurs identifiants sur Stylo) et dans lesquels se trouvent un fichier en Markdown pour le texte, un fichier en JSON pour les métadonnées et un fichier en BibTeX pour les références bibliographiques. 

Vous pouvez enfin déterminer si vous souhaitez télécharger seulement les dernières versions des articles ou bien toutes leurs versions. Dans ce deuxième cas, dans le dossier exporté, vous trouverez vos articles dans des dossiers aux noms de leurs identifiants sur Stylo, dans lesquels vous trouverez des dossiers « latest » avec les dernières versions et les versions précédentes avec leurs numéros (par exemple « 0.1 »).

Pour le moment, les articles sont sauvegardés dans le désordre sans être reliés à des corpus, qui ne sont eux pas pris en compte dans la sauvegarde. Vous pouvez toutefois exporter des corpus particuliers directement depuis la page des corpus, si vous souhaitez sauvegarder ces collections spécifiques et non les articles pris individuellement.
